# 一程欢喜 婚礼游戏邀请函

惠州 → 广州 → 茂名三城平台跳跃小游戏，含婚礼信息及纪念票高清导出。

纯静态 HTML / CSS / JavaScript，通过 GitHub Pages 发布，无需安装依赖。

婚礼信息以页面当前内容为准；宴席时间和详细场地仍待补充。本项目为可玩评审版。

宾客称呼、游戏进度与完成记录保存在当前浏览器，不上传到 GitHub。清除浏览器数据或更换域名、浏览器、设备后，不会自动恢复。

浏览器自动化已验证通关、独立多指输入、暂停及高清生成；真实手机微信的访问与保存需要实测。
